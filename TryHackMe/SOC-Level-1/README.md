## SOC Level 1 Investigation

My first case study documents an investigation involving:

**Phishing Email → Malicious Document → Payload Execution → C2 Communication → Persistence → Credential Dumping → Lateral Movement**

The objective was to investigate the attack chain, identify indicators of compromise, analyze attacker behavior, and understand how the different stages of the intrusion were connected.

## Learning Approach

I focus on understanding **why** an attack works rather than simply following commands.

For each investigation, I aim to document:

- What happened
- How it was detected
- What evidence was available
- Which tools were used
- What the attacker was attempting to achieve
- Relevant MITRE ATT&CK techniques
- Lessons learned
